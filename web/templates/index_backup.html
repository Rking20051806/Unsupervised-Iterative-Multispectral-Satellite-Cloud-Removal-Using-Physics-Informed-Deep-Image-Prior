🛰️ Atmospheric Scattering Model (ASM)

The forward imaging process under cloud and aerosol cover is mathematically modeled by the Atmospheric Scattering Model (ASM):

Ib(x) = Jb(x) · tb(x) + Ab · (1 - tb(x))

Where:

  • Ib(x): Observed reflectance for spectral band b at pixel coordinate x.
  • Jb(x): Latent cloud-free surface reflectance (to be restored).
  • tb(x): Transmission map coefficient representing the fraction of light reaching the sensor without being scattered.
  • Ab: Global atmospheric light vector corresponding to the scattering particle reflectance.

⚛️ Radiative Transfer Equation (RTE) & Wavelength Coupling

To prevent spatial ambiguity between the transmission map t(x) and surface reflectance J(x), we couple the transmission maps of all bands via the physical properties of Mie and Rayleigh scattering (Beer-Lambert Law):

tb(x) = exp(-βext(λb) · d(x))

The extinction coefficient βext(λb) is modeled as a function of the central band wavelength λb using Ångström's Law:

βext(λb) = βRayleigh(λb) + cM(x) · λb-α + βabsorption(λb)

By fitting the optical depths τb(x) = -ln(tb(x)) to this equation across bands, the optimizer solves a pixel-wise linear least squares system for the physical scene depth d(x) and aerosol concentration cM(x), guaranteeing that the estimated transmission maps are physically and spectrally consistent.

🧠 Deep Image Prior (DIP) + PINN Optimization Objective

The restoration is framed as a self-supervised task where a deep neural network parameterized by θJ, θt serves as a structural prior. The model is optimized by minimizing a multi-term Physics-Informed loss function:

Ltotal = λrecon·Lrecon + λasm·Lasm + λrte·Lrte + λndvi·Lndvi + λtv·Ltv + λsam·Lsam + λt_prior·Lt_prior + λinit·Linit

Where:

  • Lrecon (Masked Reconstruction): Optimizes top-of-atmosphere matching strictly on clear-sky pixels (where mask M = 0).
  • Lasm (Unmasked ASM): Enforces the ASM forward model over the entire image. Set to 0.0 under clouds to prevent cloud leakage.
  • Lrte (Radiative Transfer Loss): Penalty for deviation from physical wavelength-dependent extinction curve.
  • Lndvi (NDVI Consistency): Penalizes deviation in the NDVI index between original and restored images to preserve vegetation characteristics.
  • Ltv (Total Variation): Penalizes high-frequency noise to enforce spatial smoothness in the transmission map.
  • Lsam (Spectral Angle Mapper): Enforces spectral angle consistency between cloudy input and restored output on clear pixels.
  • Lt_prior (Transmission Prior): Enforces high transmission (t ≈ 1) in clear pixels and penalizes high transmission in clouds.
  • Linit (Inpainting Anchor): Anchors the output surface reflectance to the initial structural inpainting on clear pixels.

📌 1. Project Overview & Motivation

Problem Statement

Satellite imagery frequently suffers from cloud cover, haze, atmospheric scattering, and missing sensor data. Standard image completion methods (like traditional interpolation or generic GAN-based inpainting) often generate unrealistic textures, blur artifacts, or violate the physical laws of radiative transfer and reflectance.

The PINN + DIP Solution

Combines Deep Image Prior (DIP) with Physics-Informed Neural Networks (PINNs) for zero-shot reconstruction without massive pre-trained datasets:

  • DIP: Uses an un-pretrained Encoder-Decoder network whose structure acts as an implicit spatial regularizer.
  • PINN: Integrates Atmospheric Scattering Model (ASM), Total Variation (TV), Dark Channel Prior (DCP), and Spectral Cross-Correlation.

🔄 3. System Workflow & Operational Phases

Phase 1

Synthetic Inpainting & Controlled Benchmarking

  • Input: Clean, cloud-free satellite images (cloud Free images/*.png)
  • Mask Generation: Synthetic masks (Rectangle or Circle) at configurable coordinates (x_c, y_c) and sizes.
  • Purpose: Evaluates convergence speed, reconstruction accuracy (MSE, PSNR, SSIM), and loss behavior under controlled occlusions.
Phase 2

Real Cloud Detection & Atmospheric Removal

  • Input: Paired cloudy satellite images (cloud Images/*c.png) & clear references.
  • Mask Generation: Automated cloud detection using 5-layer SegmentationUNet and physical attenuation maps.
  • Purpose: Removes actual atmospheric clouds and haze using physical transmission maps t(x).

🧠 4. Deep Learning & Neural Architectures

A. High-Capacity DIP Network (HighCapacityDIPUNet)

Located in models/dip.py

  • Architecture: 5-Level Encoder-Decoder CNN architecture.
  • Design Choice (use_skip=False): Skip connections are explicitly disabled for satellite inpainting to prevent high-frequency cloud noise from bypassing the bottleneck, forcing the network to smoothly propagate surrounding land statistics into the center of the mask.
  • Channels Progression: Input (32) → 64 → 128 → 256 → 512 → Bottleneck (512) → 256 → 128 → 64 → Output (3)
  • Activation & Normalization: LeakyReLU (α = 0.2), BatchNorm2d, and final Sigmoid() activation to constrain reflectance to [0, 1].

B. Cloud Segmentation Network (SegmentationUNet)

Located in models/segmenter.py

  • Architecture: Lightweight 3-level U-Net mapping RGB images (B, 3, H, W) to probability mask (B, 1, H, W).
  • Real-time Training: Trained on-the-fly for 50 steps using binary cross-entropy loss against physical attenuation map:
    Attenuation(x, y) = max_{c ∈ {R,G,B}} | I_cloudy(x, y) - I_clear(x, y) |
    Target mask M(x, y) = 1 where Attenuation > 0.22.

📐 5. Mathematical Pipeline & Loss Formulations

During optimization, the total loss function L_total is minimized:

L_total = L_{masked_recon} + λ_{TV} L_{TV} + λ_{ASM} L_{ASM} + λ_{PR} L_{PR} + λ_{DCP} L_{DCP}
L_{masked_recon} Reconstruction MSE outside cloud
L_{TV} Symmetric TV boundary smoothness
L_{ASM} Atmospheric Scattering Model
L_{DCP} Dark Channel Prior
L_{PR} Physical Range [0,1] Penalty
1. Masked Reconstruction Loss (L_{masked_recon}):

Evaluates pixel fidelity strictly outside the cloud region (1 - M): L_{masked_recon} = (1/N) ∑ || (I_pred - I_input) ⊙ (1 - M) ||²

2. Symmetric Total Variation Loss (L_{TV}):

Enforces spatial smoothness along pixel boundaries: L_{TV} = mean( |∇_y I_pred| ⊙ M_y ) + mean( |∇_x I_pred| ⊙ M_x )

3. Atmospheric Scattering Model Loss (L_{ASM}):

Based on Koschmieder atmospheric model: I(x) = J(x)·t(x) + A·(1 - t(x)), giving L_{ASM} = || I_cloudy - (J·t + A(1-t)) ||²

4. Dark Channel Prior Loss (L_{DCP}):

Leverages the statistical observation that natural scenes have dark pixels near zero in at least one color channel: J^{dark}(x) = min_{c} ( min_{y ∈ Ω(x)} J^c(y) )

5. Physical Range Penalty (L_{PR}):

Penalizes non-physical reflectance values outside [0, 1]: L_{PR} = mean( max(0, -I_pred)² ) + mean( max(0, I_pred - 1)² )
